# Ceon Electric Brand & Design System

## Color Palette
- **Primary Navy**: #1a2744 (headers, sections, trust elements)
- **Secondary Charcoal**: #2a3f5f (backgrounds, subtle contrast)
- **Accent Gold**: #D4AF37 (CTAs, highlights, logo complement)
- **Accent Amber**: #E8B456 (hover states, secondary accents)
- **White/Light Gray**: #FFFFFF, #F3F4F6 (text backgrounds, clean spaces)
- **Dark Text**: #1a2744 (body copy on light backgrounds)
- **Gray Text**: #6B7280, #9CA3AF (secondary text, descriptions)

## Typography
- **Headings**: Cabinet Grotesk Bold/Extrabold (modern, geometric, premium feel)
- **Body Text**: Satoshi Regular/Medium (clean, readable, contemporary)
- **Size Hierarchy**:
  - H1: 3.5-4.5rem (hero headlines)
  - H2: 2.25-3rem (section titles)
  - H3: 1.5rem (card/subsection titles)
  - Body: 1rem (default text), 0.875rem (labels)

## Visual Aesthetic
- **Style**: Modern & Approachable (not stuffy, not casual)
- **Premium feel**: Metallic gold accents, depth, shadows
- **Trust-focused**: License badges, testimonials, security imagery
- **Responsive**: Mobile-first design with sticky CTAs on small screens

## Spacing & Layout
- **Grid**: Max-width 7xl (1280px), responsive padding 1rem-2rem
- **Card Border Radius**: 1.5rem-2.5rem (modern, not sharp)
- **Gap System**: 1.5rem-3rem between sections
- **Hero Padding**: pt-32 md:pt-48, pb-20 md:pb-32

## Design Tokens Summary
- **Shadows**: `shadow-sm` for cards, `shadow-xl shadow-gold/20` for CTAs
- **Hover Effects**: Color transitions to gold, lift effect (translateY), brightness increase
- **Rounded Corners**: xl (1rem) for buttons, 3xl (1.5rem) for cards, 2xl (0.75rem) for small elements
- **Transitions**: `transition-all duration-300` for smooth effects
- **Icons**: lucide-react for consistent iconography
